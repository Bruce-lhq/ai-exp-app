# AI Experiment v0.5.0

First regular release, following the v0.4.x cross-platform previews. The project remains in the 0.x stage; integration formats and APIs may evolve.

## What's new

- GPU-hosted web backend and iPhone home-screen Web App: control experiments without keeping a Mac online. Includes a GPU web source bundle and inline iSH setup in README.
- Faster mobile history transfer through compression, bounded stalled reads, loading recovery and clearer reconnection behavior.
- Delete inactive monitor records directly from experiment rows; remove them visually while the backend completes the operation.
- New shared application icon and persistent system/light/dark appearance. Screen charts follow the theme; PNG exports retain a white background.
- Guided Agent setup for desktop, CLI and iPhone, including GPU preparation, reuse of existing queues, project-specific strict resume, and separate real-device verification.
- Source installation no longer requires uv. Simplified README, dedicated manual setup and contribution guides, and aligned application/package versions.

## Downloads and setup

Choose the desktop installer or complete CLI archive for your OS and architecture. GPU-hosted phone access uses `AI-Experiment-GPU-Web.tar.gz`, a source bundle requiring a separate Python 3.12+ environment on the GPU; it is not a native iOS installer. Follow the README's Agent prompt or installation instructions.

`SHA256SUMS.txt` covers the downloadable artifacts. `verification.zip` contains target-system automated CLI, native-renderer and installer checks.

## Verification and support

- macOS Apple Silicon and the iSH → iPhone Web App workflow have real-device validation. Existing iPhone acceptance applies to the workflow, not every iOS version or network environment.
- macOS Intel, Windows x64 and Ubuntu 24.04 x64 packages are experimental support with target-system automated verification. Windows Server CI and Linux Xvfb tests do not replace Windows 11/Linux desktop human acceptance.
- Mac minimum OS is 13; CI runs on macOS 15. Older OS versions still need verification. macOS uses ad-hoc signing without Developer ID notarization; Windows installers are unsigned and need internet for WebView2 setup.
- Desktop cached analysis works offline. The phone requires its network and SSH tunnel; iOS may reclaim iSH. Phone and desktop metadata/cache are separate, while the remote agent's queue is shared.

## Upgrading

Back up your private workspace before replacing the app or GPU web backend. Stop only the old workbench backend before starting the new version; retain its configuration, database, cache and remote agent state. This does not stop remote training or queues. A version mismatch prompts you to restart the local backend.

A GPU web upgrade updates the web service, not the training environment or existing remote scheduler. No personal configuration, authentication material or experiments are included in the downloads.
